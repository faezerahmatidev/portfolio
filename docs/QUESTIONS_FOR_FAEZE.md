# پرسش‌های تکمیلی برای نهایی‌کردن رزومه فائزه رحمتی

OpenCode باید این سؤال‌ها را به فارسی و ترجیحاً در یک یا دو نوبت بپرسد. پاسخ‌ها را در فایل‌های مربوطه ثبت کند. اگر فائزه جواب سؤالی را نمی‌داند یا نمی‌خواهد پاسخ دهد، آن بخش حذف شود.

## ۱) تجربه کاری — مهم‌ترین بخش
1. اسم شرکت یا تیمی که الان در آن کار می‌کنی چیست؟ آیا اجازه داری نامش را در رزومه عمومی بیاوری؟
2. ماه و سال شروع همکاری چه زمانی بوده؟ هنوز آنجا مشغول به کاری؟
3. عنوان رسمی شغلی‌ات چیست؟ Angular Frontend Developer یا عنوان دیگری؟
4. در کار روزانه واقعاً چه کارهایی انجام می‌دهی؟ برای نمونه فقط مواردی را انتخاب کن که واقعاً انجام داده‌ای:
   - توسعه صفحه‌ها و کامپوننت‌های Angular
   - استفاده از TypeScript و JavaScript
   - پیاده‌سازی رابط از روی Figma
   - کار با API و سرویس‌های HTTP
   - فرم‌ها و اعتبارسنجی
   - مدیریت state
   - رفع باگ و نگهداری کد
   - طراحی واکنش‌گرا با CSS / Tailwind / Bootstrap
   - code review یا همکاری با تیم
   - تست‌نویسی
   - مورد دیگر
5. در چه محصول یا نوع وب‌سایتی کار می‌کنی؟ اگر محرمانه است، فقط نوع کلی محصول را بگو.
6. یک مسئله واقعی که حل کرده‌ای یا قابلیت مهمی که ساخته‌ای چه بوده؟ نتیجه‌اش چه شد؟ عدد و آمار فقط اگر واقعی و قابل اثبات است.

## ۲) مهارت‌ها
7. از Angular در محیط کاری استفاده می‌کنی؟ کدام نسخه یا قابلیت‌ها را می‌شناسی، مثلاً components، services، routing، forms، RxJS، signals؟
8. سطح تقریبی خودت در HTML/CSS، JavaScript، TypeScript و Angular را چطور توصیف می‌کنی: در حال یادگیری، پایه، متوسط، یا مسلط؟ لازم نیست به خودت درصد بدهی.
9. با REST API، RxJS، responsive design، Sass، testing یا ابزارهای دیگر هم کار کرده‌ای؟ فقط موارد واقعی را بگو.
10. React را تازه شروع کرده‌ای یا پروژه‌ای هم با آن ساخته‌ای؟

## ۳) پروژه‌ها
11. آیا پروژه‌ای در GitHub داری که خودت ساخته باشی یا اجازه نمایش آن را داشته باشی؟ اگر بله، لینک و توضیح کوتاه بده.
12. آیا پروژه کاری قابل نمایش عمومی داری؟ اگر نه، می‌توانیم پروژه‌های شخصی را بعداً طراحی کنیم؛ فعلاً چیزی جعل نمی‌کنیم.

## ۴) اطلاعات دیگر
13. تحصیلاتت چیست؟ رشته، دانشگاه/مؤسسه و سال پایان، اگر مایل به نمایش هستی.
14. سطح زبان انگلیسی‌ات برای خواندن مستندات، مکالمه و نوشتن چطور است؟
15. دنبال چه فرصت‌هایی هستی: استخدام داخل ایران، موقعیت‌های بین‌المللی، دورکاری، یا مورد دیگر؟
16. آیا می‌خواهی شهر محل زندگی نمایش داده شود؟ اگر نه، حذف می‌شود.
17. آیا تصویر پروفایل را از Gravatar استفاده کنیم یا ترجیح می‌دهی عکس دیگری بدهی؟

## ۵) رفرنس Figma
18. دو تصویر یا اسکرین‌شات طراحی Figma را ارسال کن. اگر نسخه موبایل هم وجود دارد، آن را هم بفرست.
19. آیا طراحی باید تا حد ممکن شبیه رفرنس باشد یا اجازه داریم برای خوانایی و رزومه‌محور بودن آن را بهبود دهیم؟

## قوانین استفاده از پاسخ‌ها
- پاسخ‌ها را در `PROFILE.md` و `PROJECTS.md` ثبت کن.
- خلاصه فارسی و انگلیسی را با تکیه بر پاسخ‌های واقعی بنویس.
- اگر پاسخ ناقص است، از ادعای قطعی خودداری کن.
- پیش از حذف placeholderها، اطلاعات را با فائزه تأیید کن.
