# فائزه رحمتی — رزومه و پورتفولیوی دوزبانه (محلی)

رزومه و پورتفولیوی شخصی **فائزه رحمتی**، فرانت‌اند دولوپر Angular — کاملاً دوزبانه (فارسی/انگلیسی)، با دو تم روشن و تیره، وفادار به تصاویر مرجع `docs/figma-reference-light.png` و `docs/figma-reference-dark.png`.

> ⚠️ این پروژه فقط برای **استفاده محلی** است. چیزی را deploy، push یا upload نکنید.

## فایل‌های راهنما (منبع حقیقت)

- `PROFILE.md` — اطلاعات تأییدشده فائزه (به‌روزرسانی: مهر ۱۴۰۵)
- `PROJECTS.md` — وضعیت پروژه‌ها (فعلاً نمونه‌کار عمومی وجود ندارد؛ چیزی جعل نشده)
- `DESIGN.md` — نیازمندی‌های طراحی
- `docs/QUESTIONS_FOR_FAEZE.md` — پرسش‌های تکمیلی
- `AGENTS.md` — دستورالعمل‌های دستیار

## پیش‌نیاز

- Node.js نسخه 18 یا جدیدتر (تست‌شده با Node 24)
- بدون نیاز به بک‌اند، API Key، حساب کاربری یا سرویس پولی

## ساده‌ترین راه باز کردن سایت (پیشنهاد می‌شود)

- وب‌سایت پورتفولیو: روی `start-portfolio.bat` **دابل‌کلیک** کن
- سایت رزومه: روی `start-resume.bat` **دابل‌کلیک** کن

سایت خودش در مرورگر باز می‌شود. برای بستن سرور، پنجره سیاه بازشده را ببند.

> نکته مهم: فایل `index.html` را مستقیم در مرورگر باز نکن — صفحه خالی می‌ماند. این سایت‌ها حتماً باید از طریق سرور محلی (دکمه‌های بالا یا دستورهای زیر) باز شوند.

## نصب و اجرا

```powershell
cd D:\my-portfolio
npm install
npm run dev
```

سپس مرورگر را باز کنید: `http://localhost:5173`

## بیلد و پیش‌نمایش نسخه نهایی

```powershell
npm run build      # بررسی TypeScript + ساخت خروجی در dist/
npm run preview    # مشاهده خروجی نهایی
npm run check      # فقط بررسی TypeScript بدون بیلد
```

## تغییر زبان و تم

- دکمه **English / فارسی** (بالای صفحه): تغییر کامل زبان، جهت (`rtl/ltr`) و `lang` سند
- دکمه **تم تیره / تم روشن**: تغییر تم؛ انتخاب‌ها در `localStorage` ذخیره می‌شوند
- لینک مستقیم به هر حالت (برای تست و چاپ):
  - `http://localhost:5173/?lang=fa&theme=light`
  - `http://localhost:5173/?lang=en&theme=dark`

## خروجی PDF (تأییدشده)

هر ۴ نسخه آماده در پوشه `pdf/` هست (تولیدشده و بررسی‌شده در همین محیط) — دقیقاً با ظاهر سایت، هر کدام **یک صفحه A4**:

- `pdf/resume-fa-light.pdf` — فارسی، تم روشن
- `pdf/resume-fa-dark.pdf` — فارسی، تم تیره
- `pdf/resume-en-light.pdf` — انگلیسی، تم روشن
- `pdf/resume-en-dark.pdf` — انگلیسی، تم تیره

لینک‌های داخل هر ۴ PDF فعال و قابل کلیک‌اند (بدون آدرس‌های به‌هم‌ریخته).

روش دستی برای تولید مجدد (Chrome):
1. `npm run dev` را اجرا کنید و زبان/تم موردنظر را انتخاب کنید
2. `Ctrl+P` → مقصد **Save as PDF** → حاشیه Default → مقیاس Default
3. ✅ تیک **Background graphics** را حتماً بزنید (وگرنه گرادیان و تم تیره چاپ نمی‌شود)

روش دستی برای تولید مجدد (هر زبان جداگانه):

1. `npm run dev` را اجرا کنید
2. زبان موردنظر را انتخاب کنید (دکمه English/فارسی)
3. `Ctrl+P` → مقصد **Save as PDF** → حاشیه Default → چاپ
4. برای زبان دیگر، ابتدا زبان را عوض کنید و دوباره چاپ بگیرید

استایل چاپ: دکمه‌ها مخفی می‌شوند، گرادیان حذف و لینک‌ها (GitHub/LinkedIn/Gravatar) با آدرس کامل چاپ می‌شوند تا روی کاغذ قابل استفاده باشند.

## به‌روزرسانی اطلاعات

| تغییر | فایل |
|---|---|
| متن فارسی | `src/content/fa.ts` |
| متن انگلیسی | `src/content/en.ts` |
| افزودن مهارت | همان فایل‌ها، آرایه `faSkills` / `enSkills` (بدون درصد و امتیاز جعلی) |
| افزودن پروژه تأییدشده | `src/App.tsx` (جایگزینی پیام empty state) + ثبت در `PROJECTS.md` |
| تغییر رنگ‌ها | `src/styles/tokens.css` |

ساختار کد:

- `src/components/` — `ResumeSection`، `ContactLinks`، `ExperienceItem`، `SkillGroup`، `Controls`
- `src/content/` — محتوای فارسی و انگلیسی (جدا از نمایش)
- `src/styles/` — `fonts.css` (فونت وزیرمتن self-hosted)، `tokens.css` (توکن‌های دو تم)، `app.css` (چیدمان)، `print.css` (چاپ A4)

## فونت فارسی

فونت **وزیرمتن** (variable، وزن ۱۰۰ تا ۹۰۰) به‌صورت لوکال در `src/assets/fonts/` نگه‌داری می‌شود و در بیلد داخل `dist/` باندل می‌گردد؛ هیچ درخواستی به اینترنت (گوگل‌فونتس و...) ارسال نمی‌شود و سایت کاملاً آفلاین کار می‌کند.

## وب‌سایت پورتفولیو (پوشه `portfolio/`)

علاوه بر سایت رزومه، **وب‌سایت پورتفولیو** در پوشه `portfolio/` با طرح جدید (Figma Community: نوبار، Hero با عکس، درباره من، سرویس‌ها، پروژه‌ها با فیلتر فعال، فرم تماس، فوتر) ساخته شده؛ ۶ پروژه واقعی با تامبنیل دموی زنده. راهنما در `portfolio/README.md`. اجرا:

```powershell
cd portfolio
npm install
npm run dev     # http://localhost:5174
```
